# 📄 Md. Jahirul Islam - Professional Developer CV / Resume

An elegant, modern, and print-optimized single-page Developer Resume/CV built using pure **HTML5** and **CSS3**. Tailored specifically for Full-Stack (Next.js & React) Software Engineering applications.

---

## 🌟 Key Features

- **1-Page Print Optimization (`@media print`):** Designed to fit perfectly on a single A4 page when saved or printed to PDF without breaking sections.
- **Clean & Modern UI:** Uses professional typography (`Segoe UI`), subtle borders, balanced white space, and corporate color tones (`#1e3a8a`).
- **Interactive & Secure Links:** Includes click-to-email (`mailto:`) links and secure target-blank links (`rel="noopener noreferrer"`) for Portfolio and LinkedIn.
- **Fully Responsive:** Adapts smoothly across all screen sizes (Desktop, Tablet, Mobile).
- **Relocation Ready:** Highlights immediate availability for remote roles & relocation (KSA / Remote).

---

## 🛠️ Tech Stack Used

- **HTML5:** Semantic HTML structure (`header`, `section`, `ul`, `div`).
- **CSS3:** Custom styles, Flexbox layout, CSS Media Queries for print and responsive styling.

🖨️ How to Save as 1-Page PDF
---
Open index.html in Google Chrome or Microsoft Edge.

Press Ctrl + P (or Cmd + P on macOS) to open the print menu.

Apply the following settings:
---
Destination: Save as PDF

Layout: Portrait

Scale: Custom (90% or 95%)

Background graphics: Checked ✅ (Important for badge styling)

Click Save.
